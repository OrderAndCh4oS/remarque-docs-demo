# Guide for Using a Markdown Editing Tool

## Getting Started

1. **Open the editor** – Launch the tool in your browser or desktop application.
2. **Create a new file** – Click **File > New** or press `Ctrl+N` (`Cmd+N` on Mac).
3. **Save your work** – Use `Ctrl+S` (`Cmd+S`) regularly to avoid losing progress.

---

## The Basics of Markdown

Markdown uses simple symbols to format text. Here are the most common elements:

| Element | Syntax | Result |
|---|---|---|
| Heading | `# Heading 1` | Large title |
| Bold | `**bold text**` | **bold text** |
| Italic | `*italic text*` | *italic text* |
| Link | `[text](url)` | Clickable link |
| Image | `![alt text](image.png)` | Embedded image |
| Code | `` `code` `` | Inline code |

---

## Writing and Previewing

- Use the **editor panel** on the left to write your Markdown.
- Use the **preview panel** on the right to see the formatted output.
- Toggle between panels using the **View** menu or the toolbar icons.

---

## Useful Tips

- Use `---` to insert a horizontal rule.
- Indent with four spaces or a tab to create a **code block**.
- Use `>` at the start of a line to create a **blockquote**.
- Number your lines sequentially for **ordered lists**, or use `-` for **unordered lists**.

---

## Exporting Your Document

1. Click **File > Export**.
2. Choose your preferred format: **HTML**, **PDF**, or **plain text**.
3. Select a destination folder and click **Save**.

---

| Action | Windows/Linux | Mac |

| Bold | `Ctrl+B` | `Cmd+B` |
| Italic | `Ctrl+I` | `Cmd+I` |
| Save | `Ctrl+S` | `Cmd+S` |
